---
name: feature-planner
description: >
  Plans a new feature: definition, user stories, UX flow, screens, states,
  data model, API requirements, architecture changes, implementation plan.
---

# Purpose

Define what a new feature should be before writing code.

# When This Skill Activates

- User asks to "add a feature" or "plan new feature"
- Part of ADD_FEATURE workflow
- After project is understood

# Inputs

- `project_model` (all sections)

# Responsibilities

1. Define feature purpose and priority
2. Write user stories with acceptance criteria
3. Design UX flow
4. Specify screens and components
5. Define data model
6. Specify API requirements
7. Define state management needs
8. Estimate architecture changes
9. Create implementation plan

# Expected Output

- Feature specification document
- New entries for project_model (features, screens, data_models, api_contracts)

# What This Skill Must Not Do

- Do not implement the feature
- Do not modify analyzed project

# Related Skills

- feature-mapper (provides existing features)
- screen-analyzer (provides screen patterns)
- impact-analyzer (blast radius)
- implementation-planner (phased plan)
