# Reforge Examples

This directory contains example Project Model files demonstrating Reforge's output format.

## Files

- `project-model.yaml` — Complete example for a fictional mobile app ("TaskFlow")

## About the Example

TaskFlow is a fictional task management mobile app built with Flutter. The example demonstrates:

- Project fingerprint (Flutter, BLoC, GoRouter, Material3)
- Features (task management, search, contacts, settings)
- Screens with entry/exit points, components, and states
- State machines with transitions and edge cases
- Architecture (feature-first, clean architecture)
- Design system (colors, typography, spacing)
- Product DNA (what must survive a redesign)
- Health scores with evidence
- Contradictions and dead code
- Decision log with reasoning

## Purpose

The example shows why the Project Model exists: to create a shared representation that multiple skills can read and write, enabling composition of analysis across different perspectives.
