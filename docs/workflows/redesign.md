# Redesign Workflow

## Purpose

Understand existing project, identify problems, propose improvements.

## Trigger

- "Redesign this project"
- "How should we rebuild this?"
- "Overhaul this app"

## Skills Involved

1. project-archaeologist (current state)
2. reference-analyzer (what to preserve from Product DNA)
3. redesign-planner (problems → principles → proposal)
4. impact-analyzer (architecture impact)
5. implementation-planner (phased plan)

## Output

- Current state assessment
- Problem list (categorized by product/UX/UI/engineering)
- Design principles
- Proposed product/UX/UI changes
- Architecture impact
- Migration strategy
- Implementation plan
