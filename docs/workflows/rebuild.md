# Rebuild Workflow

## Purpose

Reconstruct the product and produce an implementation strategy.

## Trigger

- "Rebuild this"
- "Create implementation plan"
- "How would you build this?"

## Skills Involved

1. project-archaeologist (fingerprint)
2. architecture-analyzer (architecture patterns)
3. design-system-extractor (design tokens)
4. implementation-planner (phased plan + file plan)
5. test-planner (test strategy)
6. documentation-generator (agent handoff)

## Output

- Architecture analysis
- Design system documentation
- Phased implementation plan
- File plan (create/modify/delete)
- Test plan
- Agent handoff document
