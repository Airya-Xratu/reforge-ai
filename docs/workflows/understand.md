# Understand Workflow

## Purpose

Analyze an existing project and produce a complete reconstruction.

## Trigger

- "Analyze this project"
- "What is this app?"
- "Reforge this"

## Skills Involved

1. project-archaeologist (fingerprint + archaeology)
2. feature-mapper (feature discovery + navigation)
3. screen-analyzer (screen inventory)
4. state-analyzer (state machines)
5. architecture-analyzer (architecture patterns)
6. ux-analyst (UX patterns + journeys)
7. ui-analyst (visual hierarchy + components)
8. design-system-extractor (design tokens)
9. product-analyst (product purpose + DNA)
10. project-health (quality scores)
11. decision-logger (record key decisions)
12. documentation-generator (agent handoff)

## Output

- Complete Project Model
- Analysis report
- Health scores
- Decision log
- Agent handoff document

## Example Agent Interaction

```
User: Analyze this Flutter project
Agent: [Loads project-archaeologist → fingerprint]
Agent: [Loads feature-mapper → feature discovery]
Agent: [Loads screen-analyzer → screen inventory]
Agent: [... continues through pipeline]
Agent: [Produces analysis report with health scores]
```
