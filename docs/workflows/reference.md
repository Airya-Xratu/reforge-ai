# Reference Workflow

## Purpose

Analyze another application as inspiration without cloning implementation.

## Trigger

- "Use this as reference"
- "Analyze as inspiration"
- "Extract patterns from this"

## Skills Involved

1. project-archaeologist (fingerprint)
2. reference-analyzer (classify patterns, produce preserve/redesign/remove decisions)

## Output

- Pattern classification (generic, product-specific, implementation detail, branding, distinctive)
- Clone→improve matrix
- Preserved product knowledge
- Decision log entries

## Key Principle

Reforge must never blindly clone an implementation. The goal is to extract useful product and design knowledge that can be independently reimplemented.
